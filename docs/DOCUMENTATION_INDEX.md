## Documentation Standards

### Format

- All documentation in Markdown format
- Code examples with syntax highlighting
- Diagrams using Mermaid where applicable
- Clear section headers and table of contents

### Maintenance

- Documentation updated with each feature release
- Version numbers and last updated dates included
- Deprecated features clearly marked
- Migration guides provided for breaking changes

### Contribution

- Documentation changes reviewed with code changes
- Examples tested before inclusion
- Screenshots updated when UI changes
- Links verified regularly
